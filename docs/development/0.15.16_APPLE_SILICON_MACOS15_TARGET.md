# 0.15.16 Apple Silicon / macOS 15+ target

Supported Mac platform is intentionally narrowed to Apple Silicon arm64 (M1 or newer) running macOS 15.0 or later. macOS 14 and older and Intel Macs are unsupported.

Native C/Swift code is built with deployment target 15.0. Tagged release packaging runs on the M1 `macos-15` runner. CI additionally builds on `macos-26` to catch current SDK changes without making Xcode 27 a product requirement.

The Stage-B CoreHID virtual-keyboard probe is optional at SDK build time. Xcode/macOS SDKs without CoreHID build the capture + legacy IOHID/Quartz probe. Newer SDKs may compile CoreHID behind `#if canImport(CoreHID)` and macOS 26 runtime availability. CoreHID must never raise the app minimum OS above 15.0.
