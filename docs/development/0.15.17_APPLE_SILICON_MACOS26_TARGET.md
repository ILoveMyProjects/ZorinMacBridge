# 0.15.17 Apple Silicon / macOS 26+ target

Supported Mac platform: Apple Silicon arm64 (M1 or newer), macOS 26.0 Tahoe or later. Intel and macOS 25 or older are unsupported.

Native streamer and capability-probe dylibs use deployment target 26.0. CoreHID is required by the Stage-B capability probe on this target. Native CI and tagged macOS packaging use the `macos-26` Apple-Silicon runner.

This release does not claim physical LoginWindow capture/input success; that remains real-device acceptance.
