# 0.15.15 — ScreenCaptureKit-only LoginWindow capture

Stage A on macOS 26 / Xcode 27 proved that `CGDisplayStream.start()` and `.stop()` are unavailable in macOS 15+ SDKs. The production streamer therefore no longer references `CGDisplayStream` at all.

LoginWindow capture on macOS 14+ uses `SCScreenshotManager.captureSampleBuffer()` and feeds the resulting image buffer into the existing VideoToolbox H.264 encoder. Logged-in Aqua capture remains continuous `SCStream`.

This change deliberately does not bypass SDK availability checks with private/dynamic symbol lookup. The six-second first-H.264 deadline and Stage D pipeline-state diagnostics remain authoritative for real-device acceptance.
