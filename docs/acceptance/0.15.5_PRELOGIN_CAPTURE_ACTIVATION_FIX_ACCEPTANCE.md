# 0.15.5 PreloginCaptureActivationFix — real-device acceptance

## TARGET

After updating while macOS is at LoginWindow, ZorinMacBridge must activate the newly installed pre-login runtime immediately and use the 0.15.4 screenshot-based LoginWindow capture path without requiring a reboot.

## Required checks

1. Start from a Mac advertising an older ZMB version while at LoginWindow.
2. Run **Update now** from Zorin.
3. Confirm update does not report success until the old pre-login process has been replaced and TCP port 45950 is listening again.
4. Refresh discovery and confirm the running Mac advertises `v0.15.5` without rebooting.
5. Connect Desktop.
6. Confirm Desktop and Video authentication succeed.
7. Confirm the client logs `First H.264 frame decoded` and visibly renders the macOS LoginWindow.
8. Confirm a failed pre-login input event does not tear down the whole control session.
9. Log in and confirm handoff to the normal Aqua Desktop.

## Failure conditions

- `update-now: OK` while the running pre-login service still advertises the previous version.
- Desktop/Video authentication succeeds but no first H.264 frame is decoded.
- LoginWindow video requires a reboot before the new release becomes active.
- A single pre-login input failure terminates the whole Desktop control channel.
