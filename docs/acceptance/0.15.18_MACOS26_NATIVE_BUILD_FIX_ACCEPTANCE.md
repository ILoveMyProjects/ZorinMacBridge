# 0.15.18 macOS 26 native build fix acceptance

Target: Apple Silicon arm64, macOS 26.0+.

## Required checks

- `tests/test_prelogin_displaystream_capture.py` is absent from the tracked source tree.
- `tests/test_prelogin_screencapturekit_only.py` is present and requires no `CGDisplayStream`.
- `ZMBCapabilityProbe.swift:imageLumaRange` reads pixels through the `raw` buffer while `withUnsafeMutableBytes` is active.
- `scripts/run-tests.sh` and `scripts/verify-release-source.sh` reject reintroduction of the obsolete CGDisplayStream test.
- Linux test suite passes.
- macOS native CI must compile both `libzmb_streamer.dylib` and `libzmb_capability_probe.dylib` on the `macos-26` runner.
- GitHub release workflow remains responsible for producing the Linux `.deb` and macOS `.dmg`.

A local Linux Swift parse is not a substitute for the macOS 26 Swift 6.3 type-check.
