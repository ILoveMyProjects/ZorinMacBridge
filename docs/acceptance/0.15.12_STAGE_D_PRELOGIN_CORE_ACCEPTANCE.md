# 0.15.12 Stage D pre-login core acceptance

## Automated gate

- `python3 -m compileall -q .` passes.
- `scripts/run-tests.sh` passes, including `test_stage_d_prelogin_core.py`.
- macOS native CI compiles `ZMBLoginInput.c`, `ZMBStreamerLib.swift`, and the Stage B capability dylib.
- shell/YAML/plist/release-source gates pass.

## Real Mac — LoginWindow ownership

1. Reboot the Mac to the physical LoginWindow.
2. Connect from Zorin. Confirm Desktop auth succeeds and Video auth succeeds without a second pairing/fingerprint prompt.
3. Open a second client connection. The first control owner must disconnect and release input before the second owner becomes active; there must never be two active LoginWindow input owners.
4. A video connection without the current Desktop `session_token` must be rejected.

## Real Mac — first frame pipeline

Before the first visible frame, server/client diagnostics should progress through:

```text
prelogin-stage=capture-frame
prelogin-stage=pixel-buffer
prelogin-stage=encode-submit
prelogin-stage=h264-written
First H.264 frame decoded: ...
```

A missing stage identifies the exact failing boundary. Do not mark video PASS from TLS auth or decoder initialization alone.

## Real Mac — login and Aqua handoff

1. With the LoginWindow image visible, enter the macOS password remotely.
2. After macOS accepts login, the client should report `LoginWindow -> Aqua handoff` / `Pre-login handoff to Aqua Desktop`.
3. The pre-login listener must release port 45950.
4. Aqua server must bind the same port without manual intervention; temporary `EADDRINUSE` is retried for at most 8 seconds.
5. The Zorin client should attempt its first reconnect after about 250 ms, then fall back to normal reconnect behavior if Aqua is not ready yet.
6. The resulting Desktop session must report `prelogin=false`; Files and the configured 1080p/2K/4K mode become available again.

## Pass condition

Stage D real-device PASS requires the complete chain: visible LoginWindow -> remote input accepted -> macOS login succeeds -> explicit handoff -> normal Aqua Desktop reconnect. Build/unit tests alone are not sufficient.
