# ZorinMacBridge 0.15.1 — Session Password Input Fix acceptance

## TARGET

A newly installed Zorin client must allow the user to type into **ZMB session password** even though remote keyboard/mouse capture defaults to enabled. Remote keyboard forwarding must start only after an authenticated Desktop session exists. A rejected session password must not loop automatic reconnects.

## Real-device acceptance

1. Install/update the Zorin client to 0.15.1.
2. Pair the Mac in **System** using the normal SSH key-pairing flow.
3. Stay disconnected from Desktop and leave **Capture keyboard & mouse** enabled.
4. Click **ZMB session password** and type a known test string. Confirm the field accepts every keystroke locally.
5. Enter the correct ZMB session password and click **Connect**. Confirm Desktop authentication succeeds and remote keyboard/mouse forwarding works after connection.
6. Disconnect, enter an intentionally wrong ZMB session password, and click **Connect** once.
7. Confirm the client reports `Authentication failed — check ZMB session password`, focuses/selects the password field, and does **not** start repeated auto-reconnect attempts.
8. Correct the password and connect again. Confirm normal Desktop connection works without repeating System pairing.

## Regression boundaries

- `Capture keyboard & mouse` remains enabled by default after a successful Desktop connection.
- Full-screen `Esc` / `Alt+Esc` handling remains local while fullscreen.
- System pairing/TLS trust is unchanged.
- No `.deb` behavior or macOS server transport behavior is changed by this hotfix.
