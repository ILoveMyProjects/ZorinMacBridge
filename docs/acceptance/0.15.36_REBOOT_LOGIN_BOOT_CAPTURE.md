# 0.15.36 Boot Pre-login Supervisor Acceptance

TARGET slice: after a full macOS reboot and before any user logs in, the system P0 LaunchDaemon must autonomously restore the ZorinMacBridge LoginWindow Desktop endpoint.

PASS requires one cold reboot to show all of the following without pressing Connect first:

- `com.ilovemyprojects.zorinmacbridge.admin` is loaded in the `system` launchd domain.
- `/usr/local/libexec/zmb-system-daemon` remains alive under launchd `RunAtLoad + KeepAlive`.
- console owner reaches `loginwindow` or `root`.
- P0 loads/starts `com.ilovemyprojects.zorinmacbridge.prelogin` in the LoginWindow domain if launchd did not do so automatically.
- the configured Desktop TCP port becomes LISTEN.
- if the helper exists but the port stays down for two P0 ticks, only the pre-login helper is restarted.
- Aqua/sleep-wake behavior is unchanged.

The later capture/input/login stages remain separately verified; this acceptance file does not claim them PASS.

## Capture continuation

After the endpoint is READY, the same reboot test must record the pre-login capture candidates in order:

1. `screencapturekit-persistent`
2. `screenshot-sample-buffer`
3. `screenshot-image-rect`

A candidate passes only after an H.264 access unit is physically written to the native data pipe and decoded by the Zorin client. The client allows 10 seconds without progress, resets that soft deadline when the pipeline/backend changes, and retains a 40-second absolute bound.
