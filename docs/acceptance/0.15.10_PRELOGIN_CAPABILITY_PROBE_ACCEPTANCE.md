## Physical LoginWindow proof

After rebooting to the normal macOS LoginWindow, run `zmb-admin capability-probe` over the already-paired System SSH channel.

Capture PASS requires all of:

- [ ] `capture_shareable_content=PASS`
- [ ] `capture_screenshot=PASS`
- [ ] `capture_luma_range` is at least 8
- [ ] `capture_result=PASS`
- [ ] `/var/tmp/zmb-capability-probe.png` exists and visually contains the LoginWindow

Input PASS requires at least one proven path:

- [ ] preferred: `input_corehid_result=PASS`
- [ ] comparison only: `input_legacy_result=PASS`

A CoreHID failure with `entitlement_hid_virtual_device=0` is a Stage-C signing/capability blocker, not evidence that virtual HID itself is broken.

The probe must never enter text or a password; it may only toggle left Shift briefly.

## Stage B exit condition

Stage B is complete only when the physical Mac result lets us classify capture and input independently as PASS, permission/entitlement blocked, or implementation failure. Do not redesign the production LoginWindow runtime before that classification exists.
