# ZorinMacBridge 0.15.0 — Prelogin Connect Fix acceptance

## Target
After a normal reboot, with the target user not logged in, Zorin must treat a live P0/System service as proof that the Mac is awake. Desktop Connect must recover/connect the LoginWindow endpoint and must not show `Waking Mac…`.

## Real-device acceptance
1. Install/update 0.15.0 on both sides.
2. Reboot the Mac and do not log in locally.
3. Confirm the physical Mac shows the macOS login window.
4. On Zorin, refresh discovery. `system online` without `desktop` is allowed briefly.
5. Click Desktop **Connect**. Expected client log: `System/P0 is online ... using session recovery instead of Wake-on-LAN`.
6. `Waking Mac…` and a magic packet must NOT appear while the System service is reachable.
7. Within the bounded recovery window the remote macOS login screen must appear.
8. Enter the macOS password remotely.
9. After Aqua starts, one reconnect is acceptable; normal Desktop/video and the selected quality settings must resume.

## If pre-login does not start
From System logs collect the P0 `logs` action. 0.15.0 includes `/var/log/zorinmacbridge-prelogin.log` and `.err` in that output.

## Security
The recovery action remains restricted by the paired SSH ForcedCommand and does not enable arbitrary shell access, automatic login, VNC, or port 5900.
