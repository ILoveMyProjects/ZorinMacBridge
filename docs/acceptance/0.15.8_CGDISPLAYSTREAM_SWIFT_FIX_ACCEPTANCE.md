## TARGET

Restore the macOS native streamer release build on Xcode 16.4/macOS 15 SDK without changing the 0.15.7 LoginWindow capture design.

## Required source conditions

- `ZMBStreamerLib.swift` uses `CGDisplayStream(dispatchQueueDisplay:outputWidth:outputHeight:pixelFormat:properties:queue:handler:)`.
- Stream lifecycle uses `displayStream.start()` / `displayStream.stop()`.
- Properties use `CGDisplayStream.showCursor`, `.queueDepth`, and `.minimumFrameTime`.
- Obsolete Swift-unavailable C spellings (`CGDisplayStreamCreateWithDispatchQueue`, `CGDisplayStreamStart`, `CGDisplayStreamStop`, `kCGDisplayStream*`) do not appear in the Swift source.
- Async pre-login code does not call `NSLock.lock()` / `unlock()` directly; it uses the synchronous scoped helper.
