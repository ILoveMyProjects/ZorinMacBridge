# 0.14.17 DesktopStateVideoControls acceptance

Run on the real Zorin + MacBook setup. The 2K/4K physical monitors are attached to **Zorin**, not to the MacBook.

1. Start with **Resolution = 1080p**, **FPS = 30**, **Quality = Balanced**. Connect. Confirm the physical MacBook desktop is the source and control/input works.
2. Change only **Quality** to Ultra. Confirm the log still says `resolution=1080p` and `fps=30`; only bitrate changes to 40 Mbit/s.
3. Change only **FPS** to 60. Confirm resolution stays 1080p and quality stays Ultra.
4. Select **2K**. Confirm a 2560×1440 virtual desktop appears remotely, the built-in MacBook panel is removed from the active workspace for this login session, and the decoded stream is 2560×1440.
5. Disconnect and press **Connect** while 2K is still selected. The Desktop/control session must connect first, the server must prepare 2K, and video must return without manually switching to 1080p.
6. Change Quality and FPS while staying in 2K. Confirm neither change returns the desktop to the physical MacBook display.
7. Select **4K**. Confirm 3840×2160 becomes active. If 4K preparation fails, the previous working 2K desktop must remain available instead of being destroyed.
8. Confirm logs do not repeat `Requested virtual desktop 3840x2160 is not active` in a permanent retry loop. ScreenCaptureKit must wait for the requested display ID.
9. Force/observe a video-only failure such as `native streamer pipe stalled for 15s`. Confirm control/input remain connected and **Full Screen** stays available while H.264 retries.
10. Select **1080p**. Confirm the virtual display is removed and the built-in MacBook display is re-enabled for the current session.
11. Let the Mac display turn off naturally. Confirm idle display-off does not automatically drop the whole server; video-only wake/retry must not tear down control.
12. Close the Zorin client. Confirm the window disappears immediately and the process exits; no shutdown hang.
13. Start the client again and confirm there is no `PIL.Image.ANTIALIAS` traceback from `pystray`.
14. Verify no automatic login, FileVault, password, permanent display configuration, or lock-screen settings changed.

Collect `~/.local/state/zorinmacbridge/client.log` plus the Mac server log if any step fails.
