# 0.15.47 — Automatic P0 / Virtual HID Setup Recovery

## TARGET

A first-time macOS Setup Assistant run must install/repair ZMB-owned P0 services and the bundled Virtual HID path without telling the user to leave the wizard and press **Enable / Repair** later.

## Required behavior

1. `install-admin.sh` invokes `install-virtual-hid.sh --prepare`; it must not wait on interactive DriverKit approval.
2. `systemsetup -setremotelogin on` is bounded to 15 seconds. A refusal/timeout becomes a manual Remote Login action, not a failed P0 install.
3. Setup Assistant automatically requests Virtual HID activation from the logged-in Aqua user.
4. If macOS requires one-time Driver Extension approval, Setup Assistant opens System Settings and keeps polling without closing or declaring success.
5. After `[activated enabled]`, Setup Assistant automatically runs privileged `--finalize`, restarts the daemon and requires the real root keyboard/mouse self-test to pass.
6. Final Setup Assistant completion is blocked while required normal Aqua setup or Virtual HID/LoginWindow-agent components are incomplete.
7. A physical reboot/LoginWindow capture proof stays `UNVERIFIED` until actually tested on the Mac.

## Out of scope

No change to capture, H.264, TLS, wake, pairing, protocol, runtime HID report format/dispatch, or Linux client behavior.
