## Physical Mac acceptance

With FileVault preboot outside scope and the Mac stopped at normal macOS LoginWindow:

1. Zorin discovers Desktop/System after reboot.
2. Desktop connection authenticates with existing TLS identity/pairing.
3. Client reports `Pre-login capture backend: screencapturekit-persistent`.
4. First H.264 frame is decoded and the real macOS LoginWindow is visible.
5. Pointer movement and click select the LoginWindow password field/account.
6. Keyboard input enters the macOS password remotely.
7. Return logs the user in.
8. Server emits LoginWindow -> Aqua handoff.
9. Client automatically reconnects to normal Aqua Desktop without re-pairing.
10. No VNC, Screen Sharing, port 5900, or third-party remote desktop service is involved.

TARGET is accepted only after all ten physical checks pass on the target Mac.
