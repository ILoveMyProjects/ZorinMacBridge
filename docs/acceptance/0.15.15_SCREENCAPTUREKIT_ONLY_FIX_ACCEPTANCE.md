# ZorinMacBridge 0.15.15 — ScreenCaptureKitOnlyFix acceptance

## Build gate

- `native/macos/ZMBStreamerLib.swift` contains no `CGDisplayStream` reference.
- macOS 26 and Xcode 27 native CI compile the streamer successfully.
- LoginWindow capture on macOS 14+ uses `SCScreenshotManager.captureSampleBuffer()`.
- Normal Aqua capture still uses `SCStream`.

## Runtime acceptance

On a real LoginWindow session:

1. Connect from Zorin.
2. Confirm video authentication succeeds.
3. Confirm pipeline state reaches `capture-frame`, `pixel-buffer`, `encode-submit`, `h264-written`, then client `First H.264 frame decoded`.
4. Confirm the login window is visible and input can be tested separately through the Stage B/F capability path.

The release is not considered real-device PASS until the first decoded frame is observed on the target Mac.
