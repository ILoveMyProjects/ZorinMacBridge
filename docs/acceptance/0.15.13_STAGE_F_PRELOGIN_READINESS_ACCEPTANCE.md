# 0.15.13 Stage F — PreloginReadinessGate acceptance

## Build / static gate

- [ ] macOS CI native gates pass on the configured Apple Silicon runners.
- [ ] `scripts/run-tests.sh` passes.
- [ ] shell/plist/YAML/release-source validation passes.

## Fresh install before LoginWindow proof

- [ ] Install a valid Stage C Developer ID/provisioned build and P0.
- [ ] Confirm the Mac GUI does **not** show READY before a capability proof exists.
- [ ] Confirm the terminal setup prints `SETUP_COMPLETE=0` and a `prelogin_capability_proof` REQUIRED item.

## LoginWindow proof

- [ ] Sign out/reboot to the normal macOS LoginWindow.
- [ ] Run the paired System `capability-probe` action from Zorin.
- [ ] Confirm the probe returns `overall=PASS`, `capture_result=PASS`, and at least one input result `PASS`.
- [ ] Confirm `/Library/Application Support/ZorinMacBridge/Admin/prelogin-capability-status` exists and contains the current `app_version` and `app_cdhash`.
- [ ] Log in and refresh Required setup; confirm the proof is shown as `PASS/current`.

## Stale proof rejection

- [ ] Update or re-sign the installed app without running a new LoginWindow probe.
- [ ] Confirm the Mac GUI returns to REQUIRED rather than READY.
- [ ] Confirm `zmb-admin status` reports `prelogin_probe_current=0` and `prelogin_probe_ready=0`.
- [ ] Run a new successful LoginWindow probe and confirm readiness returns only after the new proof matches the installed build.

## Negative probe

- [ ] Start a new capability probe and make it fail/block (for example by withholding an expected permission in a test environment).
- [ ] Confirm the previous PASS is invalidated immediately and READY is not retained.
