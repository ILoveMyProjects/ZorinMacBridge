# 0.15.35 Runtime Version Skew Guard

After a reboot test, the Linux client must log the Mac runtime version received in AUTH_OK.
A pre-login matrix is valid only when client and Mac runtime versions match exactly.
The P0/system Bonjour advertisement must expose the installed Mac app version even when Desktop is absent.
The Linux release job must not produce an artifact when the macOS native gate fails.

Physical acceptance:
- system-only discovery shows the installed Mac version;
- Desktop auth logs identical client/Mac versions;
- `runtime-version=PASS` appears before the backend matrix;
- only then are backend PASS/FAIL results accepted as evidence.
