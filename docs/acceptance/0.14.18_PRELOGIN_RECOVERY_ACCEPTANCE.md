# ZorinMacBridge 0.14.18 — PreloginRecovery acceptance

This checklist validates the two real-device risks that cannot be proven on Linux: the macOS LoginWindow capture/input path and rapid video reconfiguration.

## Preconditions

- Install the 0.14.18 Mac release while logged into the normal target user once.
- P0 pairing and the normal ZMB session password must already work.
- Do **not** enable automatic login and do not change FileVault for this test.
- Confirm `/Library/LaunchAgents/com.ilovemyprojects.zorinmacbridge.prelogin.plist` exists.

## A. Normal reboot → LoginWindow → Aqua handoff

1. From Zorin, connect normally and note the selected Resolution/FPS/Quality.
2. Use **System → Reboot**.
3. Wait for the Mac to finish normal macOS boot. If FileVault preboot requires an unlock before macOS starts, perform that separately; it is outside this feature.
4. Without touching the Mac after normal macOS loginwindow appears, use ZorinMacBridge **Connect**.
5. Expected client state: `Connected — macOS login window`.
6. Expected image: the physical macOS login screen, not a 2K/4K virtual desktop.
7. Click/focus the password field, type the account password from Zorin, and press Return.
8. Expected: login succeeds without physical keyboard/mouse interaction.
9. During transition, one short disconnect/reconnect is acceptable as the LoginWindow launchd session ends.
10. Expected after Aqua starts: normal ZMB Desktop reconnects automatically, Files becomes available again, and the previously selected 1080p/2K/4K mode is restored.

Collect on failure:

```bash
sudo tail -n 200 /var/log/zorinmacbridge-prelogin.log
sudo tail -n 200 /var/log/zorinmacbridge-prelogin.err
```

and on Zorin:

```bash
tail -n 250 ~/.local/state/zorinmacbridge/client.log
```

## B. Rapid FPS / Quality reconfiguration

1. Stay connected to the normal Aqua Desktop.
2. Change FPS and Quality several times within 1–2 seconds (for example 30 → 60 → 30 and Balanced → High → Ultra).
3. Expected: UI coalesces the burst and performs one replacement video restart after the final setting settles.
4. Expected server log: no burst of many simultaneous `TCP connection accepted` / `SSLEOFError` entries.
5. Expected: control session, keyboard/mouse, and Full Screen remain usable while video reconnects.
6. Repeat at 1080p and 2K.

## C. Failure boundaries

- If video is visible at loginwindow but clicks/keyboard do not work, capture `/var/log/zorinmacbridge-prelogin.err`. IOHID behavior under Secure Event Input is macOS-version dependent and is the main unverified runtime risk.
- If the pre-login process never starts, inspect the LaunchAgent and background-item authorization:

```bash
sudo plutil -lint /Library/LaunchAgents/com.ilovemyprojects.zorinmacbridge.prelogin.plist
sudo launchctl print gui/0/com.ilovemyprojects.zorinmacbridge.prelogin
```

- Port 5900 / Apple Screen Sharing is **not** required by this implementation.
- FileVault preboot/EFI/recovery screens are out of scope because macOS/launchd/ZMB are not running there.
